# Fira Code

Fira Code is a monospaced programming font with programming ligatures.

- Version: 6.2
- Upstream: https://github.com/tonsky/FiraCode
- License: SIL Open Font License, Version 1.1
- Copyright: 2014, The Fira Code Project Authors

The static TrueType files in `ttf/` are suitable for desktop installation.
The variable font is kept separately in `variable/`.
