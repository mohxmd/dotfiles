# Fonts

This directory contains redistributable font assets used by the dotfiles.

## Fira Code

`fira-code/` contains the Fira Code 6.2 desktop font files. Fira Code is
licensed under the SIL Open Font License, Version 1.1; see its local license
and attribution files.

## Local-only fonts

Fonts that are not redistributable, such as licensed commercial fonts, belong
under `assets/fonts-local/`. That directory is intentionally ignored by Git.
