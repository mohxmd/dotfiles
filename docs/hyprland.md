# Hyprland Quick Reference & Shortcut Guide

> **Main Modifier Key**: `Super` (`Windows Key`)  
> Modular Wayland dynamic tiling compositor with Matugen, Waybar, Rofi, and SwayNC.

---

## 1. Launch Applications

| Shortcut | Action | Application |
| :--- | :--- | :--- |
| `Super + Enter` | Terminal | Kitty |
| `Super + B` | Web Browser | Firefox |
| `Super + E` | File Manager | Dolphin |
| `Super + D` | App Launcher | Rofi Application Menu |
| `Super + Ctrl + Enter` | App Launcher | Rofi Application Menu (alternative) |

---

## 2. Window Management

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Super + Q` | Close Window | Closes focused application |
| `Super + Shift + Q` | Force Kill | Forcibly terminates active PID |
| `Super + F` | Fullscreen | Fullscreen (hides Waybar) |
| `Super + M` | Maximize | Maximized window (retains Waybar) |
| `Super + T` | Toggle Float | Switch active window between tiled & floating |
| `Super + Shift + T` | Float All | Toggle all windows on workspace to floating |
| `Super + Alt + T` | Pin Floating | Pin floating window across all workspaces |
| `Super + J` | Toggle Split | Change split direction (horizontal / vertical) |
| `Super + K` | Swap Split | Swap positions across split |
| `Super + G` | Toggle Group | Group tabbed windows together |

---

## 3. Window Navigation & Resizing

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Super + Left / Right / Up / Down` | Focus Window | Shift focus in arrow direction |
| `Super + Shift + Left / Right` | Resize Width | Shrink / expand window width by 100px |
| `Super + Shift + Up / Down` | Resize Height | Shrink / expand window height by 100px |
| `Super + Shift + H / J / K / L` | Move Window | Move window position using Vim keys |
| `Super + Alt + Arrows` | Swap Windows | Swap position with neighboring tiled window |
| `Alt + Tab` | Next Window | Cycle to next window |
| `Alt + Shift + Tab` | Previous Window | Cycle to previous window |
| `Super + Left Click (drag)` | Move Window | Move floating or tiled window with mouse |
| `Super + Right Click (drag)` | Resize Window | Resize window with mouse |

---

## 4. Workspaces

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Super + 1 ... 9, 0` | Switch Workspace | Switch to workspace 1 through 10 |
| `Super + Shift + 1 ... 9, 0` | Move to Workspace | Send focused window to workspace 1 through 10 |
| `Super + Scroll Up / Down` | Cycle Workspaces | Scroll between active workspaces |
| `Super + Ctrl + Down` | Empty Workspace | Jump to the next empty workspace |

---

## 5. Desktop Tools & System Actions

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Super + Print` | Screenshot Menu | Interactive screenshot tool (Rofi) |
| `Super + Alt + S` | Area Screenshot | Instantly capture selected screen region |
| `Super + Alt + F` | Full Screenshot | Instantly capture entire screen |
| `Super + V` | Clipboard History | Open Cliphist search via Rofi |
| `Super + Ctrl + W` | Wallpaper Selector | Visual wallpaper picker |
| `Super + Shift + W` | Random Wallpaper | Cycle to a random wallpaper & generate colors |
| `Super + Shift + B` | Restart Waybar | Reload status bar |
| `Super + Ctrl + B` | Toggle Waybar | Show / hide status bar |
| `Super + Ctrl + T` | Waybar Themes | Switch between `modern` and `minimal` themes |
| `Super + Ctrl + R` | Reload Hyprland | Reload all configuration files |
| `Super + Ctrl + L` | Lock Screen | Lock session via Hyprlock |
| `Super + Esc` | Power Menu | Open Wlogout (Lock, Logout, Suspend, Reboot, Shutdown) |
| `Super + Ctrl + P` | Power Menu | Alternative shortcut for Wlogout |

---

## 6. Hardware & Media Keys

| Key | Action | Description |
| :--- | :--- | :--- |
| `Volume Up / Down` | Adjust Volume | Raise / lower audio volume (+/- 5%) |
| `Volume Mute` | Toggle Mute | Mute / unmute speakers |
| `Mic Mute` | Toggle Mic | Mute / unmute microphone |
| `Brightness Up / Down` | Screen Brightness | Raise / lower display brightness (+/- 5%) |
| `Play / Pause` | Media Playback | Toggle play / pause (Spotify, browser, etc.) |
| `Next / Prev Track` | Media Track | Skip to next or previous media track |
